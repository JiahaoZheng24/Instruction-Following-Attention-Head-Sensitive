## 0. 一页纸

**一句话**：层级重构目标 ‖(W−Q)X‖² 只用了损失 Hessian 的输入侧。在 instruct 模型形成 attention sink 的早期 down_proj 上，输入侧 85–100% 来自 BOS 一个 token，而损失对该层输出的敏感度落在 BOS 之后的 sink 接收位置，两者在位置上错开。GPTQ 于是拿模板 token 的输出去换 BOS 的精度，在一个可移植的矩阵里写下一个沿超权重通道的伪分量；3-bit 时它在少数模型上与整张网络的短文校准解相乘，把指令跟随打崩（IFEval .150 / .412，RTN .565 / .697），而 PPL 与 MMLU 看不见。把输出侧放回、输入白化的目标 Σ_t g_t‖Δx_t‖²/‖x_t‖² 治愈全部已知崩塌并对校准协议稳健，代价是健康模型平均 −0.6、Llama MMLU −4，所以是按风险启用的修复而不是默认配方。

## 1. 协议

- **量化**：fake-quant fp 检查点（值在 b-bit 网格上），GPTQ 复现自 gptq_core（OBS 逐列补偿，act-order，g128 sym，ρ=0.05），W0 验证过 3-bit 内核不可信故不用内核。AutoRound / HQQ 用官方库（`IFEval_ar` 环境）。[§1, §9.10ag]
- **校准取样（已核实源码，§8.1d）**：GPTQ 原仓 = 随机抽 ≥2048 token 的文档取随机窗口（我们的 c4win）；GPTQModel = 每行文本单独分词、不截断、默认不拼接（我们的短文协议；他们 1024 篇，我们 128）；llm-compressor = 逐样本截断到 2048、拼接默认关（短文协议）。**两种协议都是主流默认。**
- **评测**：IFEval 541（贪心，1280 token，双 BOS 管线，所有臂一致 [§0b 协议偏差]）；GSM8K 1319 零样本 CoT；MMLU 5-shot logit；wikitext-2 PPL 2048 窗口；Multi-IF 英文三轮。种子噪声：校准种子 ±3（W66：−1.3 / +2.8 / +2.6 / −4.3）[§9.10bc]。
- **预注册**：W20 起每批先写预测再跑，落空的全部保留（§8 清单）。

## 3. 病灶（C2）

### 3.1 定位 [§9.10i–k, §9.10x–z]
- 逐位置分歧（32 条 prompt）：Llama 第 2 层输出、位置 4 `<|end_header_id|>` 相对误差 3.85（其余 0.65）；Q14 第 5 层输出、位置 2 首个 `\n` 3.96。治愈臂该位置回到 0.2–0.5。
- 凶器矩阵：Llama L1 down_proj，Q14 L4 down_proj。零比特修复：只把它改 RTN，Llama .150 → **.630**，Q14 .412 → **.751**（三次复评）；早期注意力 fp16 不治（.158）；检测器标记的 124 模块全 RTN 不治（.153）、补集 100 模块治（.615）。
- 输入结构：该 down_proj 的 BOS 输入范数 481（其余 1–2.5）/ Q14 位置 2 输入 70（其余 4–25）。校准 Hessian 秩一主导：BOS 占 A 的 .998 / 1.000。

### 3.2 解剖 [§9.10x–z]
- 模板 token 线性误差 GPTQ 2.56 对 RTN 0.28（Llama）；Q14 536 对 25。
- 误差 26% 集中在一行（行 788 = 超权重行），量化后 max|Q| 6.8 对 max|W| 0.62：OBS 在共线 BOS 通道间交换权重、被组量程截断（比特无关：4-bit 1.7 对 3-bit 2.6）。5 个超权重行 fp16 只去掉一半误差、不治（.204）：病灶是整个矩阵里所有行的共线交换，超权重行是极端实例。
- 方向（W66/W68）：GPTQ − fp16 在 L1 之后处处沿通道 788（BOS 隐状态方向 u，前 3 通道占 99%），病灶位置 4 余弦 **+.90**、幅度 3.85 倍；普通位置 0.5 倍同向。Q14 的 u 弥散（前 3 通道 53%），余弦 .49。

### 3.3 推导（理论 brief §7）[§9.10bg]
H ≈ x_0x_0ᵀ + λI ⇒ OBS 补偿 Δw_k ≈ δ_j x_{0j} x_{0k}/‖x_0‖²，即每步补偿沿 BOS 激活模式；输出误差 e_t^{(r)} ≈ c_r (x_0ᵀx_t)/‖x_0‖²。推论：方向 = 超权重行（证实）；幅度 ∝ token 与 BOS 模式的重叠（**只在极端 token 成立**：最高五分位误差 2.3× / 4× 最低，中间 60% 平，有普通量化噪声地板 [§9.10bh]）；发作位置 = prompt 里的模板标记（Llama 1.34 对普通 .62）与 Q14 的首个换行（.95 对 .17），**回复 token 几乎不受影响**（.34–.41），损伤不在生成中累积 [§9.10bj]。

### 3.4 移植：病灶可搬运，协议依赖在背景 [§9.10bh, §9.10bj]

| 目标 ← 供体的 sink down_proj | IFEval |
|---|---|
| fp16 Llama ← 短文 GPTQ 的 L1 down | .754（病灶单独不致命）|
| RTN3 Llama ← 同 | .520 |
| c4win GPTQ 背景 ← 短文病灶 | .567 |
| 短文 GPTQ 背景 ← c4win 病灶 | .136 |
| fp16 Q14 ← 短文 GPTQ 的 L4 down | .649（−17，病灶更毒但不致命）|
| 短文背景换入 c4win 的第 2 / 3 / 2–3 / 2–4 整层 | .129 / .152 / .128 / .134（不治）|
| c4win 背景换入短文的第 2–3 层 | .632（不崩）|

因果结构：病灶必要不充分（去掉治愈 .630，单独不致命 .754）；短文 GPTQ 背景必要不充分（c4win 背景 + 病灶 .567）；两者相乘才崩。背景不可定位到第 2–4 层，是全网络短文解的分布式性质；机理开放（§7）。

### 3.5 检测器：排序器，不是开关 [§9.10ae, §9.10an]
模板位置 2–7 的 GPTQ/RTN 误差比（早期 down_proj 最大值）：Llama 102、Q14 456、Nemo 60、Mistral-v0.2 31、L3.2-3B 4.7、Q7 3.1、gemma 1.95。盲测 16 模型 Spearman −0.50。跨模型无阈值（Qwen3-14B 承受 23.4 的模板误差，Llama 2.56 就死）；跨校准集也失效（c4win 检测器 301 却不崩）。乘积律（L1 误差 × block 0–1 背景）只在 damping / 比特 / 分组 / 归一化这一族内成立（13 臂 3 次前瞻命中），跨校准集落空 [§9.10x, §9.10an]。

## 4. 原理（C3）：丢掉的输出侧

### 4.1 谱系
OBD/OBS 用损失 Hessian；OBQ/GPTQ 换成层输入协方差 A = XXᵀ，即 K-FAC 分解 A ⊗ G 里 G ≡ I。KronQ（COLM 2026）证明通道级 G 在 GPTQ 逐列更新里代数上消掉；错位在**位置**上，所以要的是逐 token 的 G。

### 4.2 测量（W59/W63）[§9.10ar, §9.10ay]
每样本一次反传：A 侧 ‖x_t‖²，G 侧 ‖∂L/∂y_t‖²，按位置类别（BOS / 1–7 / 其余）算份额。

| 模型 · 校准集 | 病灶模块 | A_bos | G_bos | A·G_bos | 价格 BOS/位置 1–7：A → A·G | 3-bit GPTQ |
|---|---|---|---|---|---|---|
| Q14 · 短文 | L4 down | 1.000 | .000 | .993 | 63,380 → 717 | .412 崩 |
| Llama · 短文 | L1 down | .998 | .000 | .984 | 26,029 → 426 | .150 崩 |
| Llama · c4win | L1 down | .991 | .000 | .978 | 23,991 → 4,048 | .643 |
| Mistral-v0.3 · c4win / 短文 | L1 down | .855 / .859 | .000 | .969 | 6,909 → 217 / 455 → 129 | .172 崩 / .468 |
| Nemo / Falcon3 / Q7 · 短文 | L2 / L3 / L3 down | .925 / .501 / .850 | ≤ .004 | .954 / .662 / .335 | 163 → 133 / 20 → 9 / 8 → 3 | 不崩 |

- 普遍性（28 模型）：26 个有 sink 支配 down_proj 的模型全部 A_bos ≥ .50（多数 ≥ .93）且 G_bos ≤ .008；gemma-2 两个尺寸没有 A_bos ≥ .5 的模块（最大 .007）。**错位是必要条件不是判别量**（Q7、Nemo、Falcon3 同样错位不崩）。
- G 集中在开头 1.7% 的位置（逐 token 是中位的 10³–10⁵ 倍），chat 集下就是模板 token；BOS 的 g 低于中位（"Attention Sinks Induce Gradient Sinks"：大激活经 RMSNorm 衰减自身梯度）。
- 事后观察：病灶模块上 BOS 对开头 token 的 A 价格比在短文下 Q14 63k > Llama 26k ≫ Mistral 455 > Nemo 163 > Falcon 20 > Q7 8，前两个崩；唯一不合序 Llama c4win（24k 不崩）。n 小，只作观察。
- 注意力质量不预测脆弱性：Llama 对模板位置注意力 .011 崩，Q7 .64 不崩 [§9.10bc]。Qwen 系的 sink 在模板首个 `\n` 而非 BOS。

## 5. 修正目标（C4）

### 5.1 定义
H = Σ_t w_t x_t x_tᵀ，w_t = g_t / ‖x_t‖²，g_t = ‖∂L/∂y_t‖²（每样本一次反传，L = 该样本的逐 token 交叉熵之和），归一到均值 1。`--hess-grad-weight --hess-token-norm`，Hessian 累积处一行权重。退化情形：tnorm（g ≡ 1，W42）与 G 加权（‖x‖ ≡ 1，W60）。

## 6. 普适性四句（每句 n ≥ 15，预注册后测出）

1. 盲点普遍：28 模型，26 个有 sink 层的全部有，gemma-2 两个没有，边界 = 有没有 sink 支配层。
2. 3-bit 灾难罕见（2/32）且依赖校准协议；跨方法（AutoRound 也崩）。
3. 4-bit 无灾难无收益：17 模型 GPTQ 平均不赢 RTN，两个输 6–10 分。
4. 修正目标最坏情形有界：29 模型 × 3 协议对 RTN 从未低于 −2.7；治所有 3-bit 崩塌与两个最大的 4-bit 损失。

不成立的普适：崩塌本身；检测器阈值；同一病灶跨方法（AutoRound 是另一种）。
