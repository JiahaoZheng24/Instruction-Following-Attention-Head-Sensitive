协议：GPTQ g128 / sym / desc_act / c4-128×2048 校准；fake-quant fp 检查点；IFEval 541 条 avg4（四指标均值）；tacq = TaCQ 判据 |W|·|∇L|·|ΔW_rtn| 环内豁免；预算 ≈ 线性层参数 0.55%（7B=37.6M，8B=40.2M，14B=70M），另有 1e4–1e7 扫描。旋转 = QuaRot 式 R1（随机正交，离线融合，恒等性已验证：rotfp_llama 0.7848 ≈ fp16 0.7683）。

## 6. 机制探针

- **事后 vs 环内**：事后散点恢复 null（0.6628/0.6699 vs none 0.6717）；环内 tacq +3.0 → 散点收益属于量化过程（误差吸收器）。
- **零化探针**：fp16 下把临界 1e5 置零 → 0.1877 ≈ 崩塌 → 临界集 fp16 致命，非量化制造。
- **位移分析**：临界权重位移是随机的 4–6 倍，但 GPTQ≈RTN → 位移幅度不解释崩塌（方向/交互才是）。
- **三候选机制证伪**：desc_act 排序（no-actorder 仍崩 0.1561）、位移幅度（同上）、任务对齐（c4 掩码同效 0.6425）。
- **解剖**：通道结构化（cols 救援 0.6407 ≈ 散点 tacq）、非 super weights（sw_only 0.1625）、规模 ~1e5 相变。

## 9. 近邻论文重叠审计与定位（2026-09-03 复核）

### 9.1 TaCQ 原理对比（我们的判据来源，最近的邻居）

| | TaCQ (2504.07389, UNC) | 我们 |
|---|---|---|
| 判据 | s=\|W\|·\|∇L\|·\|ΔW\|（MSG×QAL），任务数据梯度 | **同一判据，faithful 复现**（ΔW=目标位 RTN 误差；全局分位数阈值）|
| 用法 | 混合精度实 checkpoint：top 权重存 16-bit，其余低比特 | 环内掩码 GPTQ（豁免项零误差传播），fake-quant 网格 |
| 论文类型 | **方法论文**：在所有设置全赢基线（SliM-LLM/SPQR/SqueezeLLM）| **分析论文**：何时有用、何时无用、为什么 |
| 核心主张 | 3.1-bit 恢复 96% MMLU（Llama-3-8B）；2-bit GSM8K +16 | 保护收益二值化：崩塌态 +37/+49（p<1e-4），优雅态统计为零（4 实例 CI 跨零）|
| 机制实验 | 无 | RTN 对照/事后 vs 环内/零化探针/相变/旋转杠杆/randw |
| task-conditioning | 卖点（task-specific 最强）| 边界条件：c4 掩码同效（1e5, Llama）；instruct 校准更差 |
| circuit 叙事 | 名字与动机 | 证伪：因果头电路不指导保护，判据与功能重要性解离 ρ≤0.16 |

**红线**："保护显著性权重在低比特保分"是 TaCQ 的领土——我们的救援数字必须挂 TaCQ 引用出场（"consistent with"），措辞永远是 "we adopt TaCQ's criterion as instrument"。
**待调和矛盾**：TaCQ 2-bit 大增益 vs 我们 2-bit 终末（2%/5% 预算也 0.13）。差异疑在协议（他们混合精度实存、平均 3.1bit、预算与格式不同）。写作前精读其 2-bit 配置，把我们的主张限定为"匹配预算与本协议下"。
**未决核查**（proposal §8 遗留）：TaCQ 代码仓的量化底座（per-channel/GPTQ 细节）需核实后才能写协议对比句。

### 9.2 Super Weight（2411.07191，Yu et al.，ND+Apple——合作导师学生，主动认领先行者）

他们的主张：①存在 1–6 个标量"超权重"，剪掉单个即 PPL 爆 3 个量级、zero-shot 掉到乱猜；②data-free 一次前向可定位；③超权重诱导超激活；④保护 SW+处理超激活的 RTN 量化即可高质量压缩。
与我们的关系：**"极小 fp16 致命集合存在"这一概念是他们的**——我们的零化探针是其 set 级别的类似物，必须大方引用为 lineage。差异化（全有实验背书）：崩塌相关的临界集是 **10⁵ 级、通道结构化、显著性定义**的，SW 只是其中零头；**sw_only 救不活 GPTQ 崩塌（0.1625）**——SW 保护对 RTN 式量化够用（他们的设置），对补偿式崩塌不够（我们的设置）；且 SW 检测的激活尖峰统计**反向预测** regime（Qwen 尖峰 30× 于 Llama 却优雅）。一句话定位：SW 论文回答"最小致命集是什么"，我们回答"量化崩塌需要保护的集合是什么"——二者不是同一个集合。

### 9.4 ICLR 同类先例（genre 可行性）

分析/审视类量化论文在 ICLR 有稳定生态：**LLM-KICK（ICLR 2024，压缩评测审视）**、Scaling Laws for Precision 线（2411.04330，顶会收录，genre 同型）、层剪枝无效性分析线；方法侧 GPTQ（ICLR'23）、OmniQuant/SpQR（ICLR'24）、LeanQuant（ICLR'25）说明量化本身是 ICLR 核心议题。我们相对已录取分析论文的超配项：因果机制对照全套 + 配对统计 + 可操作决策规则；短板：fake-quant 无部署内核、崩塌仅 GPTQ 家族（RTN/旋转为对照，AWQ 未测）、≤32B。

## 10. 写作脚注 / 诚实项

- Multi-IF 与 GSM8K 的 Qwen "gptq3" 参照有 packed 与 v2 两版（IFEval 差 ~1 分；GSM8K 已补 v2none 0.7779，Multi-IF 未补，正文注明）。

- 24B/32B 只有 regime 检查臂（none）；70B 留 rebuttal。
- heads 排序来自因果 ablation dev 集（与显著性/激活排序解离：ρ≤0.16）。
- detect_super_weights 在 Qwen 上有归因 bug（未用于任何最终主张；Llama 检出正常并被 sw_only 臂消费）。
