## 6. 机制探针

- **事后 vs 环内**：事后散点恢复 null（0.6628/0.6699 vs none 0.6717）；环内 tacq +3.0 → 散点收益属于量化过程（误差吸收器）。
- **零化探针**：fp16 下把临界 1e5 置零 → 0.1877 ≈ 崩塌 → 临界集 fp16 致命，非量化制造。
- **位移分析**：临界权重位移是随机的 4–6 倍，但 GPTQ≈RTN → 位移幅度不解释崩塌（方向/交互才是）。
- **三候选机制证伪**：desc_act 排序（no-actorder 仍崩 0.1561）、位移幅度（同上）、任务对齐（c4 掩码同效 0.6425）。
- **解剖**：通道结构化（cols 救援 0.6407 ≈ 散点 tacq）、非 super weights（sw_only 0.1625）、规模 ~1e5 相变。

### 6.5 Llama 2×2 全格（补档 2026-09-02，此前漏编）

纠错×保护四格：RTN 0.565 / RTN+tacq1e5 0.601 / GPTQ 0.150 / GPTQ+tacq 0.643。两个推论：①RTN 下保护只剩 +3.6 直接收益（无补偿之害可拦）——支持"保护价值≈拦下的害"；②**GPTQ+保护 > RTN+保护（+4.2）：临界集被屏蔽后补偿净有益**——机制句终版："保护拆掉补偿唯一的作案工具，而非关掉补偿"。范围：仅 Llama、1e5、单种子、p=0.03 压线；作机制支持证据，14B 复刻留 rebuttal。

## 9. 近邻论文重叠审计与定位（2026-09-03 复核）

### 9.1 TaCQ 原理对比（我们的判据来源，最近的邻居）

| | TaCQ (2504.07389, UNC) | 我们 |
|---|---|---|
| 判据 | s=\|W\|·\|∇L\|·\|ΔW\|（MSG×QAL），任务数据梯度 | **同一判据，faithful 复现**（ΔW=目标位 RTN 误差；全局分位数阈值）|
| 用法 | 混合精度实 checkpoint：top 权重存 16-bit，其余低比特 | 环内掩码 GPTQ（豁免项零误差传播），fake-quant 网格 |
| 论文类型 | **方法论文**：在所有设置全赢基线（SliM-LLM/SPQR/SqueezeLLM）| **分析论文**：何时有用、何时无用、为什么 |
| 核心主张 | 3.1-bit 恢复 96% MMLU（Llama-3-8B）；2-bit GSM8K +16 | 保护收益二值化：崩塌态 +37/+49（p<1e-4），优雅态统计为零（4 实例 CI 跨零）|
| 机制实验 | 无 | RTN 对照/事后 vs 环内/零化探针/相变/旋转杠杆/randw |
| task-conditioning | 卖点（task-specific 最强）| 边界条件：c4 掩码同效（1e5, Llama）；instruct 校准更差 |
| circuit 叙事 | 名字与动机 | 证伪：因果头电路不指导保护，判据与功能重要性解离 ρ≤0.16 |

**红线**："保护显著性权重在低比特保分"是 TaCQ 的领土——我们的救援数字必须挂 TaCQ 引用出场（"consistent with"），措辞永远是 "we adopt TaCQ's criterion as instrument"。
**待调和矛盾**：TaCQ 2-bit 大增益 vs 我们 2-bit 终末（2%/5% 预算也 0.13）。差异疑在协议（他们混合精度实存、平均 3.1bit、预算与格式不同）。写作前精读其 2-bit 配置，把我们的主张限定为"匹配预算与本协议下"。
**未决核查**（proposal §8 遗留）：TaCQ 代码仓的量化底座（per-channel/GPTQ 细节）需核实后才能写协议对比句。

### 9.2 Super Weight（2411.07191，Yu et al.，ND+Apple——合作导师学生，主动认领先行者）

他们的主张：①存在 1–6 个标量"超权重"，剪掉单个即 PPL 爆 3 个量级、zero-shot 掉到乱猜；②data-free 一次前向可定位；③超权重诱导超激活；④保护 SW+处理超激活的 RTN 量化即可高质量压缩。
与我们的关系：**"极小 fp16 致命集合存在"这一概念是他们的**——我们的零化探针是其 set 级别的类似物，必须大方引用为 lineage。差异化（全有实验背书）：崩塌相关的临界集是 **10⁵ 级、通道结构化、显著性定义**的，SW 只是其中零头；**sw_only 救不活 GPTQ 崩塌（0.1625）**——SW 保护对 RTN 式量化够用（他们的设置），对补偿式崩塌不够（我们的设置）；且 SW 检测的激活尖峰统计**反向预测** regime（Qwen 尖峰 30× 于 Llama 却优雅）。一句话定位：SW 论文回答"最小致命集是什么"，我们回答"量化崩塌需要保护的集合是什么"——二者不是同一个集合。

## 11. W13/W13b 终局批裁决（2026-09-04）——含三处主张修订

### 11.1 机制层完胜（补偿-传播机制现已过度确定）

- **事后恢复临界集救不活崩塌**：ph_crit_llama = 0.1621（none 0.1496，环内同集 0.6708）。崩塌不是"临界权重被写坏"——损伤已经通过 GPTQ 补偿**扩散进网络其余部分**，事后修复无从谈起。这是机制判别实验的最干净结局。
- **随机零化对照完美**：zero_rand_llama = 0.7761（≈fp16 0.7683），对比临界集零化 0.1877——"fp16 致命"是特异的、已校准的。
- 新增第三条机制证据：**保护不足反而有害**（见 11.2），只有"交互"框架能解释。

### 11.2 主张修订①：临界集尺度与结构是模型相关的（"1e5 普适相变"作废）

14B 预算曲线：tacq@1e5 = **0.216（比 none 0.412 更差！）**，@1e6 = 0.734，@70M = 0.782；cols@70M = **0.227（也更差，而 Llama 上 cols 有效 0.641）**。
- 修订后主张："存在 ≤0.01% 参数的临界集，**尺度随模型变化**（8B≈1e5，14B≈1e6）；**预算不足的保护会主动恶化结果**（改变补偿轨迹的又一证据）；列结构化在 Llama 有效、14B 无效——结构模型相关，cols 可部署性降级为单模型演示。"
- 遗留：0.216 < none 是个辣主张，建议补 2 个微臂（tacq1e5 种子副本 + tacq@3e5 定位过渡带）。

### 11.3 14B 崩塌的种子稳健性（含方差警示）

v2q14_none_cs1 = 0.5077（cs0 0.4116）：两种子均灾难性（−31/−41），但崩塌臂种子方差 ±10（优雅臂 ±1.5）。如实报告。

Qwen-14B 的 PPL 比值（1.35）落在优雅带（1.17–1.33）内，MMLU 也是——但生成侧灾难。

**取证更正（2026-09-04，逐响应原文审计）**：最初的"模型流畅输出错误答案"表述**错误**。真实失败模式：
- q14-none 在 IFEval 上 **69.1% 重复循环**（fp16 0.7%、tacq 4.1%、优雅带 4–7%、llama-none 92.4%），平均输出 4325 字符（≈打满 token 上限）；GSM8K 上 55.3% 循环。GSM8K 提取审计：1149 个错答案中 **0 个**在 #### 后含正确数（无提取 bug）；可解析率 99.85% 是因为循环体中含数字（如反复输出 "5×5=250"——真算错，非误判）。非退化的那 31% 响应通过率也只有 34.1%（fp16 77.6%）——损伤不全是退化。
- 与 llama 的真实区别不是"流畅 vs 乱码"，而是 **teacher-forced 与自由生成的解离**：llama 崩塌连单步预测都坏（PPL 8.2×，文本语义混乱）；q14 的**单步预测近乎完好**（PPL 1.35×、MMLU −6.4、循环片段局部通顺），但自回归自由生成落入重复吸引子。PPL/MMLU 都是 teacher-forced/单步度量，原理上探不到只在"模型吃自己输出"时才显形的失败。
- 修订后主张（措辞收窄、证据更硬）："**在我们的一个崩塌实例中，teacher-forced 指标（PPL、MMLU）完全探测不到自由生成的灾难性退化**；可靠检测需要小规模生成式探针（几十条即可——退化的输出长度打顶 + 重复率本身就是廉价检测器）。"范围声明：该解离目前 n=1（q14 cs0 检查点；cs1 的 PPL 待 W14-3 补），不得写成普适分类学。
- regime 谱系（修订版）：优雅 → 生成侧崩塌·似然隐形（q14）→ 全面崩塌·似然可见（llama）→ 终末（2-bit）。

## 13. W16 中间档裁决（2026-09-02）——分型判据确立，最终实验

**RTN 对照一锤定音**：中间档两代表的补偿效应与崩塌**方向相反**——Qwen-3B：RTN 0.1296 vs GPTQ 0.4106（补偿**帮 +28.1**）；Yi-9B：RTN 0.3201 vs GPTQ 0.4426（帮 +12.2）。对照崩塌态（补偿害 −41.5/−28.6）。**中间档=被小尺寸放大的普通退化，补偿在帮忙；崩塌=补偿行凶。"补偿效应符号"成为 regime 的机制级分型判据**（掉分只是表象，符号才是本质）。

**保护增益（配对 bootstrap）**：Qwen-3B tacq +7.35 [＋3.5, +11.1] p=0.0004（**显著但远小于救援**）；Yi-9B +1.97 [−1.3, +5.2] p=0.258（null，落在优雅带）。

**剂量-响应判决**：不是线性剂量曲线，而是**"近零平台 + 崩塌处不连续跳变"**。全景（裸量化掉分→保护增益）：−2.3→+0.8｜−8.5→+3.3｜−9.4→+3.0｜−14.4→+2.7｜−15.1→+2.0｜−24.7→+7.4｜−40.9→**+37.0**｜−61.9→**+49.3**。

**定量观察（机制章收尾句候选，谨慎陈述勿过拟合）**：保护增益 ≈ 补偿造成的净损害 + 小常数——补偿害 41.5 处增益 49.3、害 28.6 处增益 37.0；补偿帮忙处增益仅 2~7。**保护的价值就是它拦下的补偿之害。**
